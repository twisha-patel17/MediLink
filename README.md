## 📌 About MediLink

MediLink is a Full Stack MERN application that helps users discover nearby healthcare resources quickly and efficiently. It provides location-based search for hospitals, pharmacies, and blood banks using Google Maps APIs while offering secure authentication and an intuitive user experience.

---

## ✨ Features

### 🔐 Authentication

- User Registration
- User Login
- Google OAuth Login
- JWT Authentication
- Access & Refresh Tokens
- Secure Logout
- Delete Account
- Protected Routes

---

### 🏥 Healthcare Resources

- Nearby Hospitals
- Nearby Blood Banks

    - 10 KM
    - 20 KM
    - 50 KM
- Ratings Support

### 🗺️ Google Maps Integration

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/twisha-patel17/MediLink.git
```

```bash
cd MediLink
```

---

### Frontend Setup

```bash
cd client
```

```bash
npm install
```

```bash
npm run dev
```

---

### Backend Setup

```bash
cd server
```

```bash
npm install
```

```bash
npm run dev
```
